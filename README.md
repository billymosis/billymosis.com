# billymosis.com

Billy Priambodo's personal site, served at <https://billy.gatsu.org>.

Built with [Astro](https://astro.build), PIXI.js and Tailwind CSS. Deployed on Cloudflare
Workers; see [docs/deploy-cloudflare.md](docs/deploy-cloudflare.md).

## Commands

```sh
pnpm install   # install dependencies
pnpm dev       # start the dev server at localhost:4321
pnpm build     # astro check + astro build into ./dist
pnpm preview   # serve the built site locally
```
